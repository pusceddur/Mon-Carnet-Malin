# Mon Carnet Malin

> 🇫🇷 Français · 🇮🇹 [Italiano](#italiano)

**Mon Carnet Malin** est un carnet numérique pour lire, écouter et mieux comprendre ses livres et ses leçons.
Il est pensé pour les enfants francophones de 8 à 12 ans, y compris ceux qui rencontrent des difficultés de
lecture (dyslexie, etc.), sur iPad avec Apple Pencil et sur ordinateur.

🤖 **Cette application a été créée avec l'aide de l'intelligence artificielle.**

🚧 Projet en cours de développement.
